# 梨梨 · 头像管理器

SillyTavern 可安装扩展插件，由白川与梨梨制作。当前版本 **1.1.0**，基于头像管理器脚本 v0.28，**不需要安装酒馆助手**。

## 安装

1. 在酒馆中打开 **扩展 → 安装扩展**。
2. 粘贴仓库地址：`https://github.com/pear-winter/li-profile-picture-management`。
3. 确认安装，然后刷新酒馆。
4. 从聊天楼层 **编辑按钮左侧的 ♡**、**魔法棒扩展菜单 → 梨梨 · 头像管理**，或 **扩展设置 → 梨梨 · 头像管理器** 打开。

如果以前使用过头像管理器脚本，请先在酒馆助手中**停用原脚本**，避免重复运行。在同一浏览器、同一酒馆地址下，插件会继续使用原来的设置与本地图片库，无需重新上传。

## 功能

- 替换聊天头像，上传头像框，调节头像框大小与位置。
- 头像框、序列头像装饰颜色默认关闭；在最后一栏「设置」中分别开启，已有素材仍然保留。
- 替换头像区域背景、全局背景，调节位置和缩放，恢复主题默认。
- 气泡独立调节不透明度、背景模糊、底色、纸纹颜色与强度、背景明暗；明暗不会改变文字和头像的不透明度。一键完全透明会同时关闭纸纹与明暗调整。
- 「美化绑定」以封面卡片展示酒馆原生主题，支持搜索、上传封面、绑定当前单人角色。切换角色自动应用绑定主题；未绑定角色保留当前主题。角色以头像文件名标识，改名不影响绑定，替换角色头像文件后需重新绑定。群聊不自动切换。
- 「主题色」按主题单独保存配色：正文、引用、斜体、下划线、加粗、链接、代码、标题与发光，以及酒馆全局颜色变量。
- 自动读取当前主题 CSS 内的颜色，修改背景、边框、渐变、阴影、CSS 颜色变量及关键帧；可勾选读取其他可访问样式表。点色块打开圆环取色盘，支持透明度与 CSS 颜色代码。
- 支持填写不改色的标签 / CSS 选择器（包含其子元素），默认排除 pre、code；可单项还原，也可还原整套美化配色。
- 最后一栏「设置」可调管理器不透明度、毛玻璃及可选功能，保留原有入口文字 / 图片设置。
- 入口可显示文字、表情或上传的图标，可调节大小。
- 图片本地库可分类查看、删除素材。
- 管理器标签横向滑动；面板按可见屏幕百分比布局，内容区独立滚动，关闭按钮常驻底部。
- 面板配色跟随酒馆主题，滑条拖动柄为音符 ♪。

## 保存与兼容

面向 SillyTavern 1.19.0，基础头像与背景管理可用于普通主题及梨梨系列美化。特殊头像装饰依赖主题提供对应样式。

设置保存在浏览器 localStorage，上传图片保存在 IndexedDB。数据不会随 GitHub 发布，也不会自动跨设备同步。清除站点数据会同时清除本地素材和设置。插件替换的是聊天中的显示，不改写服务器中的角色卡头像文件。

美化绑定引用酒馆的主题名称，不覆盖原主题。主题改名或删除后需要重新绑定。封面图片只是预览，不会改动主题内容。CSS 改色不包括图片像素、SVG 数据图片内部、跨域不可读取样式表或内联样式中的硬编码色；继承颜色会遵循浏览器的 CSS 规则。

外链图片和内置头像框需要对应图片地址可访问；上传的本地素材保存在当前浏览器。

## 更新

在酒馆的已安装扩展列表中检查此插件更新，更新后刷新酒馆。亦可使用 GitHub 的 Code → Download ZIP 手动下载，将解压后的文件夹放入 `public/scripts/extensions/third-party/`。

## 验证

运行 `npm test`。测试覆盖插件启动与清理、重复启动、入口、旧设置键保留，以及气泡、正文、入口定制和视口适配。新增浏览器交互测试可运行 `npm run test:browser`（需安装 Playwright 及 Chromium，可用 `CHROMIUM_EXECUTABLE_PATH` 指定浏览器）：覆盖角色切换与持久化、封面上传、主题配色隔离、标签排除、环形取色、气泡质感、手机 / 桌面视口与退出清理。实际酒馆页面显示仍需在所用主题与设备中确认。
